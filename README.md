# Quiet Tuner System

React + Vite + TypeScriptで作成した、スマートフォン優先のクロマチックチューナーPWAです。マイク音声はWeb Audio APIで端末内処理し、録音・保存・外部送信は行いません。

## 起動

```bash
npm install
npm run dev
```

マイクはセキュアコンテキストが必要です。開発時の`localhost`、またはHTTPSで利用してください。

## 確認コマンド

```bash
npm test
npm run build
npm run preview
```

## 主な実装

- 25〜1,500 Hz対応のYIN検出、信頼度判定、中央値/指数平滑化、オクターブ跳躍抑制、無音タイムアウト
- クロマチック、ギター、4/5弦ベース、ウクレレと指定プリセット
- 自動/手動弦選択、カスタムチューニングの作成・編集・複製・並び替え・削除・お気に入り
- A4=415〜466 Hz、判定幅、入力感度、表記、テーマ、平滑化などの永続設定
- 柔らかな基準音、Wake Lock、振動、ライト/ダークテーマ
- Web App Manifest、Service Worker、PWAアイコン、オフライン起動

## ブラウザでの実機確認

端末や楽器によってマイク特性が異なるため、最終調整では実機でB0、E1、E2〜E4を鳴らし、設定画面の入力感度・平滑化・無音判定を調整してください。iOSではマナーモードや音声出力経路によって基準音の聞こえ方が変わる場合があります。
